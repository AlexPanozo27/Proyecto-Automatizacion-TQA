# API de SIBIO-RFID (generado de /api/docs/openapi.json el 17/11/2026)
134 operaciones en 115 rutas, 19 grupos. REST + JSON; casi todas piden sesión (token JWT en la cabecera Authorization) y el permiso del rol. Documentación interactiva Swagger UI en /api/docs (funciona sin internet); se arma sola desde el código y una prueba exige que toda ruta tenga resumen. Desde la página solo se ejecutan GET (las escrituras se habilitan con DOCS_API_ESCRITURA=1).
